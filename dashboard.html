Examination Guidelines

1. Standard 50-MCQ Format: Each examination consists of exactly 50 MCQs evaluated at 1 mark each (Total: 50 Marks).
2. 60-Minute Closing Window: The exam closes exactly 60 minutes after the scheduled start time. Late starts receive only the remaining time.
3. Automatic Countdown & Activation: The Start Exam button activates automatically at the exact scheduled IST time without refreshing.
4. Single Attempt Rule: Exactly one attempt is allowed per candidate. Submissions are permanently locked and duplicate attempts are rejected.
